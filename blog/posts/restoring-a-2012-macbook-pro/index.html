Restored A 2012 MacBook Pro, Then Installed Linux

I wanted a retro laptop, so I made it happen with an old 2012 Macbook Pro, then installed Linux on it because I can. This posts shows how I did it.

By Josh - Jul 22, 2026 | posts | software, hardware

I had some old Apple laptops lying around, all of them not working. So instead of letting them sit there rotting in my closet, why not have a weekend project?

I ripped all three apart and was able to hodge-podge something together. Two of them were 2011s, and one of them was a 2012 with a slightly better CPU. I stole the best condition battery from one, and the slightly less damaged keys and bottom half metal shell from the other into a franken-2012 MacBook Pro.

Then I bumped the ram from 4GB (2x2) to 8GB (2x4). I managed to buy the RAM before the whole RAM AI price apocalypse, but I think DDR3, especially for laptops, is still relatively safe from it anyways.

Once booted, it was on an ancient OSX Lion and the trackpad was bent. (forgot to take a pic of that) but I was able to simply bend the brace under the click pad back into place a bit, and boom, it looked fine and worked great.

Lastly, it was more difficult than it should have been, but I was able to get it all the way up to Catalina and install a RuneScape Client to play OSRS on it.

It was a serious nostalgia trip, I was playing a 20-year-old+ game on a decade old laptop from my childhood.

I tried to use OpenCore Patcher and some hacks to get a more modern apple OS on it, but that didn’t seem to work, and I read in a few places it gets really slow on older hardware anyway, so I ditched the idea.

I considered stopping here, but I had the itch to see if I could install Linux on it and make it “modern,” if you will.

I had several low-resource-usage distros to choose from, but I just went with base Debian 13 and decided to install only what I needed like basic drivers, etc.

For the Linux install, I just follow the typical Linux install steps from a flash drive, but with an extra “Apple-specific” step to reach the flash drive. Just a warning, I have been told it can be a pain in the @$$ to get older versions of OSX on older hardware after you wipe it, so be careful.

  1. Ensure you are plugged into Ethernet. There are not drivers that will use WIFI on this machine yet.
  2. Make an installer flash drive
  3. Reboot while holding the "option" button
  4. Select the UEFI drive
  5. You should be greeted by the normal Linux installer flow.

During the Install steps, there are a few minor exceptions:

  • It may ask to detect hardware for "non-free". Just select yes so it can figure out what to do with your Ethernet connection despite it saying you should plug something in. If it fights you, then say no, we are going to install additional drivers later, but you may have to move them over from a flash drive in this case.
  • Unless you compressed the OS and made a new drive and have free space/formatted partition BEFORE starting, you may be forced to erase the entire disk despite what it says about making partitions. If you don't want to, you can always just exit/reboot and start over.

Install Necessary Drivers

So if you go the Debian route as I did, lots of stuff, including the fan control, Wi-Fi, and battery control drivers, won’t be working simply because they are not installed.

At the very least, nothing that will talk to the Apple hardware or drivers. This is dangerous for an older laptop, and it will overheat if you don’t do this right.

Luckily, there are awesome people on awesome open source projects that pave the way for insane people like me to install Linux on a laptop from 2012 for whatever reason.

Wi-Fi Drivers

You will need to be plugged into an Ethernet cable, or you will need to manually move the drivers over with a flash drive. I highly recommend just plugging the laptop into a router via a cable.

open /etc/apt/sources.list

Ensure this line looks something like this

deb http://deb.debian.org/debian/bookworm main contrib non-free-firmware non-free

Immediately Run an update/upgrade, I recommend a reboot as well.

sudo apt update
sudo apt upgrade

Then install the drivers.

sudo apt install linux-headers-amd64 broadcom-sta-dkms
# OR
sudo apt install linux-image-amd64 linux-headers-amd64 broadcom-sta-dkms

The Wi-Fi Drivers for (Broadcom BCM4331) Can be a bit annoying. So ensure to reload the wireless kernel module to trigger the hardware.

sudo modprobe -r b43 b44 b43legacy ssb brcmsmac bcma
sudo modprobe wl
# OR
sudo modprobe -r b43 bcma wl
sudo modprobe wl

Install fan drivers

sudo apt install mbpfan
sudo systemctil restart mbpfan

Install battery drivers

sudo apt install tlp tlp-rdw
sudo tlp start

Unplug then plug the charge back in after 5 sec, preferably do a reboot or two.

Install a Firewall like UFW or Similar

Don’t forget to set up some kind of firewall and lock down the machine a bit. I have detailed isntructions here. Again, I recommend a reboot then ensure everything is running as expected.

Results

This was way more fun then it should have been, and it feels good to get something that can actually do some modern work from 2012, and after I put the case on it, it looks so retro and fun.

I couldn’t recommend this project more if you have old parts laying around, or are willing to pickup some old used hardware.

I found old MacBooks are relatively cheap on used on Ebay if you are bored and willing to put in some elbow grease for a retro machine. I recommend at a minimum using the 2012, and would also recommend bumping to a 2013 and snagging an i7 for a bit more horsepower.
