Restored A 2012 MacBook Pro, Then Installed Linux

I wanted a retro laptop, so I made it happen with an old 2012 MacBook Pro, then installed Linux on it because I can. This post shows how I did it.

By Josh - Jul 22, 2026 | posts | software, hardware

I had some old Apple laptops lying around, all of them not working. Instead of letting them sit there rotting in my closet, why not have a weekend project?

I ripped all three apart and was able to hodgepodge something together. Two of them were 2011 models, and one was a 2012 with a slightly better CPU (i5-3210M). I stole the best condition battery from one, and the slightly less damaged keys and bottom half metal shell from the other to build a franken 2012 MacBook Pro.

Then I bumped the RAM from 4GB (2x2) to 8GB (2x4). I managed to buy the RAM before the whole AI RAM price apocalypse, but I think DDR3, especially for laptops, is still relatively safe from it anyway.

Once booted, I found myself on an ancient version of OS X Lion, and the trackpad was slightly bent. I forgot to take a picture, but I was able to simply bend the brace under the clickpad back into place a bit, and then it worked perfectly.

Lastly, it was more difficult than it should have been, but I was able to update up to Catalina and install a RuneScape client to play OSRS on it.

It was a serious nostalgia trip, I was playing a 20-year-old+ game on a decade+ old laptop from my childhood.

YES, I eventually clean the gross stuff off the screen. I didn't get to the Linux install until later. I don't know what the previous owner did to this poor screen but it was really hard to get off 💀.

Linux?

I tried to use OpenCore Patcher and some hacks to get a more modern macOS on it, like Monterey, but that didn’t seem to work, and I read in a few places it becomes unbearably slow on older hardware anyway, so I ditched the idea.

I considered stopping here, but I had the itch to see if I could install Linux on it and make it feel “modern,” if you will.

I had several low-resource-usage distros to choose from, but I just went with base Debian 13, and decided to install only what I needed like basic drivers, etc.

For the Linux install, I followed the typical Linux install steps from a flash drive, but with an extra “Apple-specific” step to reach the flash drive. Just a warning, I have been told it can be a pain in the arse to get older versions of OSX back on older hardware after you wipe it, so be careful.

  1. Ensure you are plugged into Ethernet. No drivers that understand WiFi are installed on this machine yet
  2. Make an installer flash drive
  3. Reboot while holding the "option" button
  4. Select the UEFI drive
  5. You should be greeted by the normal Linux installer flow

During the Install steps, there are a few minor exceptions:

  • It may ask to detect hardware for "non-free". Just select yes so it can figure out what to do with your Ethernet connection despite it saying you should plug something in. If it fights you, then say no, we are going to install additional drivers later, but you may have to move them over from a flash drive in this case.
  • Unless you compressed the OS and made a new drive and have free space/formatted partition BEFORE starting, you may be forced to erase the entire disk despite what it says about making partitions. If you don't want to, you can always just exit/reboot and start over.

Install Necessary Drivers

So if you go the Debian route as I did, lots of stuff, including the fan control, Wi-Fi, and battery control drivers, won’t be working simply because they are not installed.

At the very least, nothing that will talk to the Apple hardware or drivers. This is dangerous for an older laptop, and it will overheat if you don’t do this right.

Luckily, there are awesome people on awesome open source projects that pave the way for insane people like me to install Linux on a laptop from 2012 for whatever reason.

Wi-Fi Drivers

You will need to be plugged into an Ethernet cable, or you will need to manually move the drivers over with a flash drive. I highly recommend just plugging the laptop into a router via a cable.

open /etc/apt/sources.list

Ensure this line looks something like this

deb http://deb.debian.org/debian/bookworm main contrib non-free-firmware non-free

Immediately Run an update/upgrade, I recommend a reboot as well.

sudo apt update
sudo apt upgrade

Then install the drivers.

sudo apt install linux-headers-amd64 broadcom-sta-dkms
# OR
sudo apt install linux-image-amd64 linux-headers-amd64 broadcom-sta-dkms

The Wi-Fi Drivers for (Broadcom BCM4331) Can be a bit annoying. So ensure to reload the wireless kernel module to trigger the hardware. Double check you are installing the correct drivers for your model!

sudo modprobe -r b43 b44 b43legacy ssb brcmsmac bcma
sudo modprobe wl
# OR
sudo modprobe -r b43 bcma wl
sudo modprobe wl

Fan drivers

Without this, the laptop will most likely overheat under any real load.

sudo apt install mbpfan
sudo systemctl restart mbpfan

Battery Drivers

Required if you want to monitor your battery life and reliably charge the machine.

sudo apt install tlp tlp-rdw
sudo tlp start

Unplug, then plug the charger back in after 5 sec, preferably do a reboot or two.

Don’t forget to set up some kind of firewall and lock down the machine a bit. I have some instructions here. Again, I recommend a reboot then ensure everything is running as expected.

Results

Restoring this laptop was way more fun and easy to complete than I was expecting. It also feels good to restore something from 2012 that can still do some modern work. After I put the case on it, it looks super retro and fun, just like I wanted.

I could not recommend this project more if you want an old retro MacBook. If you have old parts lying around and are willing to pick up some used hardware, it is super easy and relatively cheap.

Older MacBooks seem to be much cheaper used on eBay if you are willing to put in some elbow grease. I recommend using at least the 2012 model, and I would also recommend bumping to a 2013 and snagging an i7 for a bit more horsepower, but that can start getting more pricey.
